# Pharmacy Management Application

A desktop application for managing prescriptions and medication stock, developed using Java Swing and MySQL.  
The system allows efficient handling of prescriptions and associated medications.

## Features
- Manage prescriptions (create, view, delete)
- Associate multiple medications with a prescription
- Track medication stock
- Database integration using MySQL

## Tech Stack
- Java (Swing for GUI)
- MySQL (Database)
- JDBC (Database connectivity)

## Database Structure
- `prescription` table: stores prescription information
- `medicament` table: stores medication details
- `ligne_med` table: association between prescriptions and medications

## Getting Started

### Prerequisites
- Java JDK installed
- MySQL Server installed

### Setup
1. Import the database schema into MySQL
2. Configure database connection in the project
3. Run the application from your IDE

## Purpose
This project was developed to practice desktop application development, database design, and CRUD operations.

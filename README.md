# Pharmacy Management Application

A desktop application developed using Java Swing and MySQL for managing prescriptions and medication stock.

## Features
- Create, view, and manage prescriptions
- Associate multiple medications with a prescription
- Track medication stock
- Store and retrieve data using a MySQL database

## Tech Stack
- Java (Swing)
- MySQL
- JDBC

## Database Structure
- `prescription`: stores prescription information
- `medicament`: stores medication details
- `ligne_med`: links prescriptions with medications

## Setup
1. Import the database schema into MySQL
2. Configure the database connection in the project
3. Run the application from your IDE

## Purpose
This project was created to practice desktop application development, database integration, and CRUD operations.

# Pharmacy Management Application

A desktop application developed using Java Swing and MySQL for managing ordonnances and medication stock.

## Features
- Create, view, and manage ordonnances
- Associate multiple medications with an ordonnance
- Track medication stock
- Store and retrieve data using a MySQL database

## Tech Stack
- Java (Swing)
- MySQL
- JDBC

## Database Structure
- `ordonnance`: stores ordonnance information
- `medicament`: stores medication details
- `ligne_med`: links ordonnances with medications

## Setup
1. Configure a MySQL database connection in the project
2. Run the application from your IDE

## Notes
The database schema is not included in this repository.  
The application structure and database interactions are fully implemented, and the schema can be easily recreated or adapted based on project needs.

## Purpose
This project was created to practice desktop application development, database integration, and CRUD operations.
